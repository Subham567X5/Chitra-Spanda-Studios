## Usage Instructions / ব্যবহার নির্দেশাবলী

### English
1. **Accessing the Portal**: Open the main login page of the staging/development environment.
2. **Tenant Resolution**: Use `mumbai-studio` for roles P-02 through P-16, P-20 through P-22. Use `academy` for roles P-17 through P-19.
3. **MFA Verification**: In development/testing environments, when prompted for MFA, use the code `123456` or scan the mock QR displayed on the screen.

### বাংলা
১. **পোর্টাল অ্যাক্সেস**: স্টেজিং/ডেভেলপমেন্ট এনভায়রনমেন্টের প্রধান লগইন পৃষ্ঠাটি খুলুন।
২. **টেন্যান্ট রেজোলিউশন (ম্যাপিং)**: P-02 থেকে P-16 এবং P-20 থেকে P-22 ভূমিকার জন্য সাবডোমেন বা টেন্যান্ট ফিল্ডে `mumbai-studio` ব্যবহার করুন। P-17 থেকে P-19 ভূমিকার জন্য `academy` ব্যবহার করুন।
৩. **এমএফএ (MFA) যাচাইকরণ**: ডেভেলপমেন্ট/টেস্টিং এনভায়রনমেন্টে এমএফএ কোডের অনুরোধ করা হলে `123456` কোডটি ব্যবহার করুন অথবা স্ক্রিনে প্রদর্শিত মক কিউআর (QR) স্ক্যান করুন।
